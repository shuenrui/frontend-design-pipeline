# Frontend design bootstrap

For every frontend task that can change visual design, layout, UX, responsive
behavior, interaction, accessibility, copy, theming, motion, or design-system
coherence, load the `frontend-design-pipeline` skill before loading any other
frontend design skill or editing files. Let that skill route Impeccable,
Anthropic frontend-design, the Leonxlnx Taste skills, and the ui-ux-pro-max
design-system data engine. Do not independently stack overlapping aesthetic
skills.

Skip this only for backend-only work or a purely mechanical frontend change
with no visible or UX effect.
